Description

## What is this?

A project built for Hack Club Stardance, an online summer program where teens build technical projects and ship them to the world.

## How to run it

Open index.html in a browser. The live preview in the studio is the same markdown that this README renders from.

## Features

- Live markdown preview that rebuilds as you type
- Tag list with add and remove
- Zero dependency backend for GitHub auth
- Sequential push of every file to a new repo

## Tags

`web`, `test`

## About

Built with plain HTML, CSS and JavaScript. The backend is a small Express server that handles GitHub OAuth so the client secret never reaches the browser.

Made for Hack Club Stardance, 2026.
